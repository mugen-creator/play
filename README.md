# iPhone ショートカット 入門ガイド

iPhone / iPad に標準搭載されている **「ショートカット」アプリ** の使い方を、基礎から実践まで体系的に学べる日本語ガイドです。プログラミングの知識がなくても、タップとドラッグだけで「自分専用の自動化」を作れるようになることを目指します。

## このガイドについて

- 対象: ショートカットを触ったことがない〜なんとなく使っている初心者の方
- 必要なもの: iPhone または iPad（iOS 13 以降。新しい機能ほど最新 iOS 推奨）
- 標準アプリの「ショートカット」を使うので、追加の購入は不要です

## クイックスタート（3分で体験）

1. ホーム画面で **「ショートカット」** アプリを開く
2. 右上の **「＋」** をタップ
3. **「アクションを追加」** → 検索欄に「テキスト」と入力して **テキスト** アクションを追加
4. テキスト欄に「こんにちは！」と入力
5. もう一度 **「アクションを追加」** → 「読み上げる」を検索して **テキストを読み上げる** を追加
6. 下部の再生ボタン（▶）をタップ → iPhone が「こんにちは！」と読み上げます 🎉

これだけで「複数のアクションを順番に実行する」というショートカットの本質を体験できます。詳しくは [01-shortcuts-basics.md](docs/01-shortcuts-basics.md) から読み進めてください。

## 学習の進め方

```
基礎を理解する          手を動かす             応用する
01 → 02 → 03 → 04   →   06（レシピを試す）  →   05（自動化）
```

まずは 01〜04 で仕組みを理解し、06 のレシピを実際に作って慣れ、最後に 05 のオートメーションで「自動で動く」状態を目指すのがおすすめです。
