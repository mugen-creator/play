# 1. ショートカットとは？

[← 目次に戻る](../README.md)

## ひとことで言うと

ショートカットとは、**iPhone でいつも手作業でやっている操作を「ボタン1つ」にまとめる自動化ツール**です。

たとえば、毎朝「天気を確認 → 今日の予定を見る → 音楽を流す」という操作をしているなら、それを1つのショートカットにまとめて、タップ一発で全部実行できます。

## 「アクション」を積み木のように並べる

ショートカットは **アクション（命令）** を上から順番に並べて作ります。料理のレシピに似ています。

```
┌─────────────────────────────┐
│ アクション1: 現在地の天気を取得  │
├─────────────────────────────┤
│ アクション2: 今日の予定を取得    │
├─────────────────────────────┤
│ アクション3: 結果を読み上げる    │
└─────────────────────────────┘
        ↓ 上から順に実行
```

各アクションは「1つの仕事」をします。これを組み合わせることで、複雑な処理も作れます。**コードを書く必要はなく、アクションをタップで追加・並べ替えするだけ**です。

## どこにある？どう動かす？

ショートカットアプリには、作ったショートカットが「カード」として並びます。実行する方法はたくさんあります。

| 実行方法 | 説明 |
| --- | --- |
| アプリ内でタップ | ショートカットアプリでカードをタップ |
| ホーム画面 | ウィジェットやアイコンとしてホーム画面に置く |
| Siri に話しかける | 「Hey Siri、◯◯」でショートカット名を呼ぶ |
| 共有シート | 写真やリンクの「共有」ボタンから呼び出す |
| 自動実行（オートメーション） | 時間・場所・操作をきっかけに自動で動かす（[第5章](05-automation.md)） |
| 戻るタップ | iPhone 本体の背面をトントンと叩いて起動（設定 > アクセシビリティ > タッチ > 背面タップ） |

## 2種類のショートカット

ショートカットには大きく2つのタイプがあります。

### ① 手動で実行するショートカット
自分でタップしたり Siri で呼んだりして動かすもの。**「ショートカット」タブ**に並びます。

### ② オートメーション（自動実行）
「朝7時になったら」「家に着いたら」「充電器に接続したら」など、**条件をきっかけに自動で動く**もの。**「オートメーション」タブ**で作ります。詳しくは [第5章](05-automation.md) で扱います。

## 何ができるの？（イメージ）

- 🏠 家に着いたら Wi-Fi をオンにして照明を点ける
- 🔋 バッテリーが20%を切ったら低電力モードにする
- 🚗 CarPlay に接続したら通勤プレイリストを再生する
- 📸 撮った写真をまとめてサイズ変更して保存する
- 💬 「いま帰る」とよく送る相手に定型メッセージを送る
- 🧮 消費税込みの金額を計算する電卓を作る

「いつも同じ手順でやっている操作」があれば、それはほぼショートカットにできます。

## まとめ

- ショートカット = アクションを順番に並べた**自分専用の自動化**
- コードは不要、**タップとドラッグだけ**で作れる
- 手動実行と自動実行（オートメーション）の2種類がある
