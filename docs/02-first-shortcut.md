# 2. 最初のショートカットを作る

[← 目次に戻る](../README.md)

実際に手を動かして、ショートカットの基本操作を覚えましょう。ここでは **「タップすると今日の予定を読み上げてくれる」ショートカット** を作ります。

## 完成イメージ

```
[ボタンをタップ]
   ↓
今日のカレンダー予定を取得
   ↓
「今日の予定は◯件です」と読み上げ
```

## ステップ・バイ・ステップ

### 1. 新規ショートカットを作成

1. **「ショートカット」アプリ**を開く
2. 「ショートカット」タブで右上の **「＋」** をタップ
3. 空のショートカット編集画面が開きます

### 2. アクションを追加する

1. 画面中央（または下部）の **「アクションを追加」** をタップ
2. 上部の検索欄に **「今日の予定」** または **「カレンダー」** と入力
3. **「今日の予定を検索」**（"Find Calendar Events" 系）をタップして追加

> 💡 アクションは「検索して選ぶ」のが基本です。名前がうろ覚えでも、キーワードで探せます。

### 3. もう1つアクションを追加

1. 再び **「アクションを追加」** をタップ
2. 検索欄に **「読み上げる」** と入力
3. **「テキストを読み上げる」** を追加

### 4. アクション同士をつなぐ（マジック変数）

「テキストを読み上げる」の入力欄をタップすると、**「カレンダー予定」** のような青いタグ（マジック変数）を選べます。これを入れると、前のアクションの結果（=今日の予定）がそのまま読み上げられます。

> マジック変数については [第4章](04-variables.md) で詳しく説明します。今は「前の結果を次に渡せる」とだけ覚えればOKです。

### 5. テスト実行

画面下部の **再生ボタン（▶）** をタップ。今日の予定が読み上げられれば成功です 🎉
（カレンダーへのアクセス許可を求められたら「許可」してください）

### 6. 名前を付けて保存

1. 上部のショートカット名（「新規ショートカット」）をタップ
2. **「今日の予定」** など分かりやすい名前を付ける
3. アイコンの色や記号も変えられます
4. 右上の **「完了」** をタップ

## 編集画面の見方

```
┌──────────────────────────────────┐
│  ＜ 今日の予定          ⌄  完了    │  ← 名前・設定
├──────────────────────────────────┤
│  [アクション1] 今日の予定を検索      │
│  [アクション2] テキストを読み上げる   │  ← アクションが縦に並ぶ
│                                  │
│         ＋ アクションを追加         │
├──────────────────────────────────┤
│   ▶ （再生＝テスト実行）            │  ← 動作確認
└──────────────────────────────────┘
```

## よく使う操作まとめ

| やりたいこと | 操作 |
| --- | --- |
| アクションを追加 | 「アクションを追加」をタップして検索 |
| アクションを並べ替え | 長押ししてドラッグ |
| アクションを削除 | 左にスワイプ、または長押し → 削除 |
| 設定を変える | アクション内の青い文字・入力欄をタップ |
| テスト実行 | 下部の ▶ ボタン |
| 名前/アイコン変更 | 上部のタイトルをタップ |

## 練習問題

慣れるために、以下を自分で作ってみましょう。

1. **「テキスト」アクション**で好きな言葉を入力し、**「テキストを読み上げる」**でしゃべらせる
2. **「現在のバッテリー残量を取得」** → **「通知を表示」** でバッテリー残量をポップアップ表示する
3. 上記2を改造して、読み上げに変えてみる
