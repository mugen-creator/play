# 3. アクションとは

[← 目次に戻る](../README.md)

## アクション = ショートカットの「部品」

アクションは、ショートカットを構成する **1つ1つの命令** です。
「天気を取得する」「通知を表示する」「メッセージを送る」など、それぞれが小さな仕事を担当します。これを積み重ねて1つの処理を作ります。

## アクションの基本構造

多くのアクションは「**入力 → 処理 → 出力**」という形をしています。

```
   入力              アクション            出力
（前の結果や設定） →  〔処理を行う〕  →  （次に渡せる結果）

例：
"こんにちは" → 〔テキストを読み上げる〕 → （なし／音声）
今日の日付  → 〔日付を書式設定〕     → "2026年6月27日"
```

ある **アクションの出力**が、次の **アクションの入力**になって連鎖していく、というのが基本の流れです。

## アクションの探し方

アクションは数百種類あります。すべて覚える必要はなく、**検索して見つける**のが基本です。

- 「アクションを追加」→ 検索欄にキーワード（例:「写真」「メール」「計算」）を入力
- アプリ別（カテゴリ別）に絞り込むこともできます
- よく使うものは自然と覚えていきます

## 知っておくと便利な代表的アクション

### 入力・出力系
| アクション | 何をする |
| --- | --- |
| テキスト | 文字列を作る・入れ物にする |
| 数字 | 数値を作る |
| 入力を要求 | 実行時にユーザーに入力させる |
| 通知を表示 | ポップアップで知らせる |
| テキストを読み上げる | 音声で読み上げる |
| 結果を表示 | 画面に結果を出す |

### 制御フロー系（重要）
| アクション | 何をする |
| --- | --- |
| **If（もし〜なら）** | 条件によって処理を分ける |
| **繰り返す（Repeat）** | 指定回数だけ繰り返す |
| **各項目を繰り返す（Repeat with Each）** | リストの全項目に同じ処理をする |
| メニューから選択 | 実行時に選択肢を出して分岐する |
| 待機 | 指定秒数だけ止める |

### データ操作系
| アクション | 何をする |
| --- | --- |
| 変数を設定 | データに名前を付けて保存（[第4章](04-variables.md)） |
| 計算 | 四則演算をする |
| テキストを置き換え | 文字を置換する |
| リストから項目を取得 | 一覧から1つ取り出す |
| 辞書 | キーと値のセットを扱う |

### アプリ連携系
| アクション | 何をする |
| --- | --- |
| メッセージを送信 | iMessage / SMS を送る |
| メールを送信 | メールを作成・送信 |
| URL を開く | Safari やアプリを開く |
| URL の内容を取得 | Web API を呼ぶ（応用） |
| 写真を選択 / 保存 | 写真ライブラリを操作 |

## 制御フローの例：If（条件分岐）

「もし〜なら」で処理を変えられます。If アクションを入れると **If / それ以外 / If の終わり** の3段ができ、間にアクションを挟みます。

```
[現在のバッテリー残量を取得]
┌ If （残量 が 20 より小さい）─────────┐
│   [低電力モードをオンにする]          │
├ それ以外 ───────────────────────────┤
│   [通知を表示「バッテリーは十分です」] │
└ If の終わり ────────────────────────┘
```

## 制御フローの例：繰り返し

リスト（複数の項目）に同じ処理をしたいときは「各項目を繰り返す」を使います。

```
[アルバムの写真を取得]   ← 複数枚
┌ 各項目を繰り返す ──────────────┐
│   [イメージのサイズを変更]       │  ← 各写真に適用
│   [写真アルバムに保存]          │
└ 繰り返しの終わり ──────────────┘
```

「繰り返し項目」というマジック変数で、いま処理中の1件を参照できます。

## まとめ

- アクションは「入力 → 処理 → 出力」の部品
- すべて覚えず、**検索して見つける**
- **If / 繰り返し**などの制御フローを使うと一気に表現力が上がる
