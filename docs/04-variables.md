# 4. 変数とマジック変数

[← 目次に戻る](../README.md)

変数は「**データを入れておく名前付きの箱**」です。ショートカットでデータを自在に扱うための最重要トピックです。難しく聞こえますが、仕組みはシンプルです。

## なぜ変数が必要？

アクションの結果を「あとで使いたい」「別のアクションに渡したい」場面はとても多いです。そのときに使うのが変数です。

```
[名前を入力してもらう] → "田中さん" を箱に保存
            ↓
[メッセージ作成] → 箱を呼び出して "田中さん、こんにちは"
```

## 2種類の変数

ショートカットには大きく2つの変数があります。**まずはマジック変数だけ覚えればOK**です。

### ① マジック変数（Magic Variable）★まずはこれ

**どのアクションの出力でも、後ろのアクションから直接参照できる**仕組みです。明示的に「保存」しなくても使えるので、とても便利です。

- アクションには自動で出力が生まれます（例:「テキスト」アクションの結果）
- 入力欄をタップ → **「変数を選択」** から、前のアクションの出力（青いタグ）を選ぶだけ
- タグには元のアクション名が付くので分かりやすい

```
[テキスト：こんにちは]  ←ここの出力が…
        ↓
[テキストを読み上げる：(テキスト)]  ←青タグで参照
```

> 💡 編集中にアクションの出力名（青字）を引っ張って、後ろの入力欄にドロップする感覚です。

### ② 名前付き変数（Set Variable）

「**変数を設定**」アクションで、好きな名前を付けて保存する方法です。
同じデータを何度も使い回したいときや、繰り返しの中で値をためていくときに使います。

```
[変数を設定：合計 = 0]
┌ 各項目を繰り返す ──────────────┐
│  [計算：合計 + 繰り返し項目]      │
│  [変数を設定：合計 = (計算結果)]  │  ← 同じ箱を上書きしてためる
└────────────────────────────────┘
[結果を表示：(合計)]
```

| | マジック変数 | 名前付き変数 |
| --- | --- | --- |
| 作り方 | 自動（出力を選ぶだけ） | 「変数を設定」で明示的に作る |
| 使いどころ | 直前の結果をサッと渡す | 値を保持・上書き・使い回す |
| おすすめ度 | ★まず最初に使う | 慣れてきたら |

## 特別な変数（用意済みの便利な箱）

入力欄の「変数を選択」には、最初から使える特別な変数があります。

| 変数 | 中身 |
| --- | --- |
| **ショートカットの入力** | 共有シートなどから渡されたデータ |
| **クリップボード** | いまコピーしている内容 |
| **現在の日付** | 実行した瞬間の日時 |
| **デバイスの詳細** | デバイス名・iOS バージョンなど |
| **尋ねるたびに入力** | 実行時にその場で入力を求める |

## データの「型」を意識する

変数の中身にはいくつかの種類（型）があります。アクションは扱える型が決まっているので、噛み合わないときは変換します。

| 型 | 例 | 変換アクションの例 |
| --- | --- | --- |
| テキスト | "こんにちは" | テキスト |
| 数値 | 42 | 数字 |
| 日付 | 2026/06/27 | 日付 / 日付を書式設定 |
| リスト（配列） | [写真1, 写真2] | リスト |
| 辞書 | {名前: 田中, 年齢: 30} | 辞書 / 辞書の値を取得 |
| ファイル/画像 | 写真.jpg | — |

> 「数字が必要なのにテキストが入っている」といったエラーが出たら、間に変換アクションを挟むと解決することが多いです。

## ミニ実例：簡単な割り勘計算

```
[入力を要求：「合計金額は？」（数字）] → 金額
[入力を要求：「何人？」（数字）]       → 人数
[計算：金額 ÷ 人数]                  → 1人あたり
[結果を表示：「1人 (計算結果) 円です」]
```

- 「入力を要求」の出力をマジック変数として計算に渡す
- 計算結果をマジック変数として表示に渡す

これだけで、繰り返し使える割り勘ツールの完成です。

## まとめ

- 変数 = データを入れる名前付きの箱
- **まずはマジック変数**（前の出力を選ぶだけ）を使いこなす
- 値をためる・使い回すときは**名前付き変数**
- 噛み合わないときは**型変換**を挟む
