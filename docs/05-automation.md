# 5. オートメーション（自動実行）

[← 目次に戻る](../README.md)

オートメーションは、**「きっかけ（トリガー）」が起きたら自動でショートカットを実行する**仕組みです。タップすら不要になり、iPhone が「気を利かせて」動いてくれるようになります。

## 手動ショートカットとの違い

```
手動ショートカット:  自分でタップ・Siri で起動  →  実行
オートメーション:    条件（時間・場所・操作）   →  自動で実行
```

## 作り方

1. ショートカットアプリ下部の **「オートメーション」** タブを開く
2. 右上の **「＋」** → **「個人用オートメーションを作成」**
3. **トリガー（きっかけ）** を選ぶ
4. 実行したい **アクション** を組み立てる
5. 完了

## 主なトリガーの種類

| 分類 | トリガー例 |
| --- | --- |
| ⏰ 時間 | 特定の時刻 / アラーム / 就寝・起床 |
| 📍 場所 | 到着 / 出発（自宅・職場・任意の場所） |
| 🔌 接続 | 充電器に接続 / Wi-Fi に接続 / Bluetooth 接続 / CarPlay |
| 📱 操作 | App を開く・閉じる / NFC タグ / 集中モードの切替 |
| 🔋 状態 | バッテリー残量 / 低電力モード / 画面ロック |
| 💬 通信 | メッセージ受信 / メール受信 |

## 「実行の前に尋ねる」設定が超重要

オートメーションには **「実行の前に尋ねる」** というスイッチがあります。

- **オン**：実行時に「実行しますか？」と確認が出る（誤動作を防げる）
- **オフ**：確認なしで**完全自動**で実行される

> ⚠️ 完全自動にしたい場合（例: 家に着いたら自動でWi-Fiオン）は、このスイッチを**オフ**にします。最近の iOS では多くのトリガーで完全自動が可能です。最初は「尋ねる」をオンにして、動作を確認してからオフにするのがおすすめです。

## 実例1：就寝時刻に自動で整える

```
トリガー：午後11時（時刻）
アクション：
  [低電力モードをオンにする]
  [集中モード「おやすみ」をオンにする]
  [明るさを 20% に設定]
```

## 実例2：職場に着いたらマナーモード

```
トリガー：到着（職場）
アクション：
  [サウンドと触覚を消音にする]
  [Wi-Fi をオンにする]
```

## 実例3：充電開始でショートカット起動

```
トリガー：充電器に接続
アクション：
  [もしバッテリーが 80% より大きいなら 通知を表示「もう十分です」]
```

## 実例4：NFC タグでベッドサイドを自動化

NFC タグ（数百円で購入可）をベッドサイドに貼り、iPhone をかざすと…

```
トリガー：NFC（登録したタグ）
アクション：
  [アラームを設定 午前7時]
  [集中モード「おやすみ」をオン]
  [リラックスする音楽を再生]
```

## オートメーションのコツ

- **最初は「尋ねる」をオンに**して挙動を確認 → 慣れたらオフで完全自動化
- 位置情報トリガーは「位置情報サービス」をオンにしておく必要がある
- バッテリー節約のため、トリガーが多すぎないよう整理する
- うまく発火しないときは [第7章 トラブルシューティング](07-troubleshooting.md) を参照

## まとめ

- オートメーション = トリガーで**自動実行**される仕組み
- 時間・場所・接続・操作など多彩なきっかけが使える
- **「実行の前に尋ねる」**のオン/オフで自動化の度合いを調整する
