# 6. 便利なショートカット集（レシピ）

[← 目次に戻る](../README.md)

そのまま作れる実用ショートカットのレシピ集です。各レシピは「アクションの並び」を上から順に追加していけば完成します。まずは1つ作って、動く楽しさを体験してください。

> 表記ルール：`[ ]` が1つのアクション、インデントは制御フロー（If・繰り返し）の中身を表します。

---

## レシピ1：定型メッセージ「いま帰る」

よく送る相手に、ワンタップで定型文を送ります。

```
[メッセージを送信：「いま帰ります🏠」 宛先：（家族を指定）]
```

- 「メッセージを送信」アクションを追加し、本文と宛先を設定するだけ
- 名前を「いま帰る」にして、ホーム画面に追加すると便利

---

## レシピ2：割り勘計算機

```
[入力を要求：「合計金額は？」 種類：数字]      → 金額
[入力を要求：「何人で割る？」 種類：数字]      → 人数
[計算：(金額) ÷ (人数)]                      → 結果
[結果を表示：「1人あたり (結果) 円」]
```

- 「入力を要求」の出力をマジック変数として計算に渡すのがポイント
- 端数を丸めたいときは「数値を丸める」アクションを計算の後に追加

---

## レシピ3：消費税込み価格の計算

```
[入力を要求：「税抜き価格は？」 種類：数字]    → 価格
[計算：(価格) × 1.1]                        → 税込
[結果を表示：「税込 (税込) 円」]
```

---

## レシピ4：低電力モードのワンタップ切替

```
[低電力モードを取得]                          → 現在の状態
┌ If （低電力モード が オン）─────────────┐
│   [低電力モードをオフにする]               │
├ それ以外 ─────────────────────────────┤
│   [低電力モードをオンにする]               │
└ If の終わり ──────────────────────────┘
```

- トグル（切替）のお手本。状態を取得 → If で反転、という王道パターン

---

## レシピ5：クリップボードの URL を QR コード化

コピーしておいた URL を QR コードにして表示します。

```
[クリップボードを取得]                        → テキスト
[QR コードを生成：(クリップボード)]            → 画像
[クイックルックで表示：(QR コード)]
```

---

## レシピ6：選んだ写真をまとめてリサイズ

```
[写真を選択（複数を許可：オン）]              → 写真リスト
┌ 各項目を繰り返す ───────────────────────┐
│   [イメージのサイズを変更：幅 1080]        │
│   [写真アルバムに保存]                    │
└ 繰り返しの終わり ──────────────────────┘
[通知を表示：「リサイズして保存しました」]
```

- 「各項目を繰り返す」で複数ファイルを一括処理する典型例

---

## レシピ7：今日の天気を読み上げる

```
[現在の天気を取得]                            → 天気
[テキストを読み上げる：(天気の状況) (気温)]
```

- 朝のオートメーション（[第5章](05-automation.md)）と組み合わせると「目覚まし天気予報」に

---

## レシピ8：メニューで分岐するランチャー

実行時に選択肢を出して、選んだものに応じて動作を変えます。

```
[メニューから選択：「何をする？」]
┌ ケース「音楽」───────────────────────┐
│   [プレイリストを再生：お気に入り]       │
├ ケース「ナビ」───────────────────────┤
│   [経路を表示：自宅]                    │
├ ケース「メモ」───────────────────────┤
│   [新規メモを作成]                      │
└ メニューの終わり ───────────────────┘
```

- 1つのショートカットに複数機能をまとめられる便利パターン

---

## レシピ9：スクリーンショットを自動でトリミングして共有

```
[最新のスクリーンショットを取得]
[イメージを切り取る]
[共有：(切り取った画像)]
```

---

## レシピ10：水分補給リマインダーの記録

```
[ヘルスケアサンプルをログ：水 200mL]
[通知を表示：「水分を記録しました💧」]
```

- 「ヘルスケア」アクションで健康データを記録できる

---

## アレンジのヒント

- 完成したショートカットは **ホーム画面に追加** したり **Siri** で呼べる
- レシピ同士を組み合わせて自分だけの大きなショートカットを作れる
- うまく動かないときは [第7章 トラブルシューティング](07-troubleshooting.md) へ
