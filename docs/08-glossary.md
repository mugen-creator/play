# 8. 用語集

[← 目次に戻る](../README.md)

ショートカットを学ぶうえで出てくる用語をまとめました。困ったときの辞書として使ってください。

| 用語 | 読み/英語 | 意味 |
| --- | --- | --- |
| ショートカット | Shortcut | アクションを順番に並べた自動化の単位。1つの「カード」 |
| アクション | Action | ショートカットを構成する1つ1つの命令（部品） |
| トリガー | Trigger | オートメーションを起動するきっかけ（時刻・場所・操作など） |
| オートメーション | Automation | トリガーに反応して自動実行されるショートカット |
| 変数 | Variable | データを入れておく名前付きの箱 |
| マジック変数 | Magic Variable | アクションの出力を、後ろのアクションから直接参照する仕組み |
| 名前付き変数 | Named Variable | 「変数を設定」で明示的に名前を付けて保存する変数 |
| 入力 | Input | アクションが受け取るデータ |
| 出力 | Output | アクションが返す結果。次のアクションの入力になる |
| ショートカットの入力 | Shortcut Input | 共有シートなどから外部より渡されるデータ |
| 制御フロー | Control Flow | If・繰り返しなど、処理の流れを制御するアクション群 |
| If | イフ | 条件によって処理を分岐するアクション |
| 繰り返す | Repeat | 指定回数だけ処理を繰り返すアクション |
| 各項目を繰り返す | Repeat with Each | リストの全項目に同じ処理を適用するアクション |
| 繰り返し項目 | Repeat Item | 繰り返しの中で、いま処理している1件を指す変数 |
| 辞書 | Dictionary | キーと値の組でデータを持つ型（例: 名前→田中） |
| リスト | List | 複数の項目を並べた型（配列） |
| 型 | Type | データの種類（テキスト・数値・日付・画像など） |
| 共有シート | Share Sheet | 写真やリンクの「共有」ボタンから出るメニュー。ここからショートカットを呼べる |
| クイックルック | Quick Look | 画像やファイルをその場でプレビュー表示する機能 |
| 集中モード | Focus | おやすみ・仕事など、通知を制御するモード |
| NFC タグ | NFC Tag | かざすと反応する小型のシール。オートメーションのトリガーに使える |
| 背面タップ | Back Tap | iPhone 背面を叩いてショートカットを起動するアクセシビリティ機能 |
| ウィジェット | Widget | ホーム画面やロック画面に置ける小窓。ショートカットを配置できる |
| iCloud リンク | iCloud Link | ショートカットを他人と共有するための URL |
