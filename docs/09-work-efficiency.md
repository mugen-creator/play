# 9. 仕事効率化レシピ集

[← 目次に戻る](../README.md)

仕事の「毎日くり返す細かい作業」をショートカットに任せて、時間と集中力を取り戻すためのレシピ集です。各レシピは [第6章](06-recipes.md) と同じく、アクションを上から順に追加すれば完成します。

> 表記ルール：`[ ]` が1つのアクション、インデントは制御フロー（If・繰り返し）の中身を表します。

## どこから始める？（おすすめ順）

| まず試したい | レシピ |
| --- | --- |
| すぐ効果を感じる | [1. 定型文をワンタップ送信](#レシピ1定型文をワンタップ送信) / [3. 議事録メモを即作成](#レシピ3会議の議事録メモを即作成) |
| 集中して作業したい | [5. 集中モード一発オン](#レシピ5集中作業モードを一発でオン) |
| 自動で動かしたい | [9. 始業・終業の自動化](#レシピ9始業終業を自動化オートメーション) |

---

## レシピ1：定型文をワンタップ送信

「了解しました、確認します」など、よく送る業務連絡をワンタップで。

```
[テキスト：「お疲れさまです。確認しました。追って対応いたします。」]
[クリップボードにコピー]
[通知を表示：「定型文をコピーしました」]
```

- メール・チャットどれにも貼れるよう、あえて**コピー**にしておくと汎用的
- 相手が固定なら「メッセージを送信」に変えて直接送信も可

---

## レシピ2：今すぐ「会議に遅れます」連絡

```
[テキスト：「申し訳ありません、5分ほど遅れます。」]
[メッセージを送信：(テキスト) 宛先：（上司やチームを指定）]
```

- 背面タップ（[用語集](08-glossary.md)）に割り当てると、歩きながらでも送れる

---

## レシピ3：会議の議事録メモを即作成

会議名と日付が入った議事録テンプレートを一瞬で用意します。

```
[入力を要求：「会議名は？」 種類：テキスト]      → 会議名
[現在の日付を取得]
[日付を書式設定：(現在の日付) 形式：2026年6月27日]  → 日付
[テキスト：
  # (会議名)
  日付：(日付)
  出席者：
  ## 決定事項
  -
  ## ToDo
  - [ ]
]
[新規メモを作成：(テキスト)]
[メモを開く]
```

- 「メモ」を「Notes」「Obsidian」など使っているアプリに差し替えてもOK

---

## レシピ4：選択テキストを要約してコピー

共有シートから使う想定。長文を選んで共有 → 整形してコピー。

```
[ショートカットの入力を受け取る（テキスト）]
[テキストを置き換え：改行を「 」に]            → 1行化
[クリップボードにコピー]
[通知を表示：「整形してコピーしました」]
```

- 設定で「共有シートに表示」をオンにすると、Safari やメールの選択範囲から呼べる
- AI 連携アクション（後述）を使える環境なら、ここで本格的な要約も可能

---

## レシピ5：集中作業モードを一発でオン

ポモドーロ的に「25分の集中」を作ります。

```
[集中モード「仕事」をオンにする]
[明るさを 70% に設定]
[タイマーを開始：25分]
[プレイリストを再生：集中用BGM]
[通知を表示：「25分間、集中しましょう💪」]
```

- 終了時に自動で集中モードを切るには、オートメーション（[第5章](05-automation.md)）と組み合わせる

---

## レシピ6：経費レシートを撮って保存

```
[書類をスキャン]                              → スキャン画像
[現在の日付を取得]
[日付を書式設定：(現在の日付) 形式：2026-06-27]  → 日付
[ファイルを保存：(スキャン画像) 名前：「領収書_(日付)」 場所：（経費フォルダ）]
[通知を表示：「領収書を保存しました」]
```

- 保存先を iCloud Drive やファイルアプリの経費フォルダにすると、月末がラクに

---

## レシピ7：今日の予定を朝イチでまとめ読み

```
[今日の予定を検索]                            → 予定リスト
[未完了のリマインダーを検索]                   → ToDoリスト
[テキスト：
  ▼今日の予定
  (予定リスト)
  ▼やること
  (ToDoリスト)
]
[結果を表示：(テキスト)]
```

- 「結果を表示」を「テキストを読み上げる」に変えれば、支度しながら耳で確認できる

---

## レシピ8：通勤時間を会社に共有

到着予定時刻を計算して連絡します。

```
[移動時間を取得：目的地（職場）]              → 所要時間
[現在の日付を取得]
[日付を調整：(現在の日付) に (所要時間) を加算]  → 到着予定
[日付を書式設定：(到着予定) 形式：時刻のみ]      → 時刻
[メッセージを送信：「(時刻) 頃に着きます」 宛先：（チーム）]
```

---

## レシピ9：始業・終業を自動化（オートメーション）

オートメーション（[第5章](05-automation.md)）と組み合わせる例です。

**始業（平日 9:00／職場に到着）**
```
トリガー：到着（職場）
アクション：
  [集中モード「仕事」をオン]
  [Wi-Fi をオン]
  [今日の予定を検索 → 通知を表示]
```

**終業（平日 18:00）**
```
トリガー：午後6時（平日）
アクション：
  [集中モード「仕事」をオフ]
  [明日の予定を検索 → 通知を表示]
  [通知を表示：「お疲れさまでした。明日の予定を確認しましょう」]
```

---

## レシピ10：作業ログ（タイムトラッキング）

ボタンを押すたびに「作業内容＋時刻」を1ファイルに追記していきます。

```
[入力を要求：「何の作業？」 種類：テキスト]      → 作業
[現在の日付を取得]
[日付を書式設定：(現在の日付) 形式：HH:mm]      → 時刻
[テキスト：(時刻) (作業)]
[ファイルに追加：(テキスト) ファイル：作業ログ.txt（改行付き）]
[通知を表示：「記録しました：(作業)」]
```

- 1日の終わりにファイルを見れば、何にどれだけ時間を使ったか振り返れる

---

## AI（要約・文章作成）と組み合わせたい場合

要約・返信文の下書き・翻訳などを本格的にやりたい場合は、対応する AI アクションや「URL の内容を取得」での API 連携が使えます。これは初心者向けの範囲を超える応用なので、必要であれば専用のガイドを用意できます（最初の質問で挙がっていた「自作API/サーバーと連携」の領域です）。

## ホーム画面に「仕事フォルダ」を作る

作った仕事用ショートカットは、ホーム画面に**ウィジェットのスタック**としてまとめると一覧で押せて便利です。Siri から「議事録メモ」のように名前で呼ぶ運用もおすすめです。
